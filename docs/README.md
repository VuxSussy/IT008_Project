# Tài liệu dự án flashcard

Repo đang ở giai đoạn khởi tạo. Các tài liệu dưới đây mô tả **quy trình và kế hoạch đề xuất**. Cập nhật chúng khi nhóm chốt công nghệ, lịch nộp và phân công.

| Tài liệu | Nội dung |
| --- | --- |
| [Quy trình làm việc nhóm và Git](01-git-workflow.md) | Đầu việc, nhánh, commit, PR, review và tiêu chí hoàn thành |
| [Timeline phát triển app](02-project-timeline.md) | Phạm vi MVP, kế hoạch 6 tuần, mốc kiểm tra và rủi ro |
| [Bảng từ viết tắt](99-abbreviation.md) | Giải nghĩa thuật ngữ dùng trong dự án |

**Cần chốt trước khi bắt đầu:** ngày khởi động, hạn nộp, số thành viên, nền tảng (web/mobile), công nghệ và cách lưu dữ liệu. Sau đó cập nhật timeline theo ngày cụ thể và phân công người phụ trách từng mốc.
