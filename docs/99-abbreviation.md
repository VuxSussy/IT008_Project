# Bảng từ viết tắt

Các thuật ngữ xuất hiện trong tài liệu dự án và khi làm app flashcard.

| Viết tắt | Tiếng Anh | Ý nghĩa trong dự án |
| --- | --- | --- |
| App | Application | Ứng dụng flashcard |
| CRUD | Create, Read, Update, Delete | Bốn thao tác tạo, xem, sửa, xóa bộ thẻ hoặc thẻ |
| DB | Database | Cơ sở dữ liệu lưu nội dung học, nếu dự án dùng DB |
| Git | Git | Hệ thống quản lý phiên bản; đây là tên riêng, không phải chữ viết tắt |
| GitHub | GitHub | Nền tảng lưu repo và trao đổi qua issue, PR; đây là tên riêng |
| MVP | Minimum Viable Product | Bản tối thiểu có đủ chức năng cốt lõi để dùng và demo |
| PR | Pull Request | Đề nghị gộp thay đổi từ một nhánh vào nhánh chính để được review |
| QA | Quality Assurance | Hoạt động đảm bảo chất lượng, gồm kiểm tra và theo dõi lỗi |
| UI | User Interface | Giao diện người dùng: màn hình, nút, biểu mẫu |
| UX | User Experience | Trải nghiệm người dùng khi thao tác với app |

**Thuật ngữ liên quan:** “deck” là bộ thẻ; “flashcard” là thẻ học gồm mặt trước và mặt sau; “issue” là đầu việc hoặc lỗi được ghi lại; “review” là xem xét thay đổi trước khi gộp.
