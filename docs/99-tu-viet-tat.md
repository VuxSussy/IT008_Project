# 99 - Các từ viết tắt thông dụng

## 1. Từ viết tắt cần biết
| Từ viết tắt | Biểu diễn đầy đủ |
|---|---|
| `feat/` | feature |
| `PR/` | Pull Request |
| `gh` | github |
| `docs` | document |
| `MVP` | Minimum Viable Product |
| `GUI` | Graphical User Interface |
